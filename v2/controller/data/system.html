    Link diagnostics

    -

    Listen: the controller stays silent for 8 s and notes everything that arrives (no echo possible). While listening, restart the gate: its “hello” must be received (complete transmit chain of the gate). Or, gate unplugged, tie the input of the gate's module (wire from J1-5) to ground: the module forces the line to 0, 00 bytes must arrive (gate module and cable). A TX↔RX loopback on the gate side is invisible from here: these modules already hear their own transmission.
